# Security

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/YASS-Ltd/yama-python/security/advisories/new), not in a public issue. We'll acknowledge your report and keep you updated until it's fixed.

Never include a real API key or customer data in a report. If a key may have leaked, revoke it in the Yama portal under **Settings › API keys** straight away.
